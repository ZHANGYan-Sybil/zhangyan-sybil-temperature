# Process

## Tools
I used Doubao. It helped me summarise the assignment requirements at the early stage and provided an outline and corresponding logic for the workflow. It interpreted the original `plot.py` code, generated the plot script based on my description of the chart, and assisted with code interpretation, iterative adjustments, and overall project bug checking.

## Kept
I kept the final gradient-coloured line solution.
Colour can better convey the feeling of temperature, not merely showing numerical changes over time. It can intuitively deliver the thermal sensation of different periods to viewers.

## Rejected
I rejected the initial single-colour line segment solution.
I found that the first version also had an issue with the x-axis ticks, which failed to fully display data for June.
